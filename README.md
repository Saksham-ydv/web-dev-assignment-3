# Lab 3 – Responsive Personal Portfolio Website

## Description
This project is an improved version of my Lab 2 personal portfolio website. It uses HTML and CSS to create a responsive one-page portfolio.

## Files
- `index.html` – webpage structure and content
- `style.css` – design, layout, responsiveness, hover effects and animation
- `sakshampics.jpeg` – profile photo

## Features
- Flexbox for the header and hero section
- CSS Grid for Skills and Projects cards
- Media queries for tablet and mobile screens
- Relative CSS units such as rem and percentages
- Hover effects and CSS transitions
- A CSS keyframe animation
- About, Skills, Projects and Contact sections

## How to view
Open `index.html` in a web browser.

## Responsive testing
Test the page at desktop width, tablet width (around 800px), and mobile width (around 600px or less) using the browser's developer tools.
